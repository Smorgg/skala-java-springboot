# 프로젝트
현재 User Entity와 Product Entity가 구성되어 있고 이 정보에 대한 CRUD를 처리하고 있다.
너는 여기에서 
1. 사용자는 제품을 선택해서 주문을 넣을 수 있다
2. 주문이 들어가면 최초 주문은 주문 대기/완료 --> 결체 대기/완료 ---> 배송 대기/완료 로 상태를 가진다.
3. 제품, 결제, 배송은 주문에 연관되어 있다.
4. 각 상태 변경은 주문에 들어가서 상태를 클릭하면 주문 완료 결제 대기/완료 배송 대기/완료로 상태가 변화한다


# 해야 할 작업
1. 주문 Entity, 결제 Entity, 배송 Entity 가 추가되어야 한다.
2. 각 Entity 별 Service와 Controller를 추가한다. 


# 사용자 화면
화면은 tymeleaf 로 작성
1. 상품 검색/등록 관리
2. 사용자 검색/등록/삭제 관리
3. 주문 관리에서는 제품 목록이 보이고 주문 버튼을 클릭하면 사용자 선택이 있고 사용자 선택 OK 하면 주문 완료
4. 주문 완료 상태에서 클릭을 통해 결제대기/결제 배송 대기/배송으로 상태 전환


# 코딩 조건
1. 이미지 아이콘은 사용하지 마라
2. 학습용 코드로 복잡하지 않고 절차적으로 이해 가능하도록 코드를 작성해라
   
# 문서 작업
1. 현재 코드를 기준으로 spring boot을 배운 학생이 스스로 코드를 작성하도록 실습 가이드를 작성한다
2. 너무 상세하게 작성하지 말고 무엇을 해야 하는지 중심으로 가이드를 작성한다.
3. 작성해야 할 항목은다음과 같다
   - 최종 목표 모습
   - 주요 적요 적용해야 할 기술
   - API 목록 과 설명
   - Entity 목록과 역할 그리고 속성 (타입을 정의하는 것이 아닌도메인 관점에서 속성)
4. 사용자 시나리오 (흐름을 설명하면 이 흐름을 API 연결을 검토할 수 있도록)
